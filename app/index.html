System Governance

How NABAT-AI implements responsible AI design — deterministic pipelines, mandatory citations, and hallucination prevention grounded in the actual running architecture.

01
Concept 1
RAG — Triple Hybrid Retrieval
BM25 sparse search across all 3 text variants (manuscript · standard · dialectal) + GATE-AraBERT-v1 768-dim dense semantic search + ColBERT token-level. HyDE generates a hypothetical verse to bridge modern Arabic → Khaleeji dialect. Reciprocal Rank Fusion merges all signals.
BM25(ms∪std∪dial) + GATE-AraBERT + ColBERT → RRF → Cross-Encoder → 3-level stanza-aware results
02
Concept 2
Agents — LangGraph State Machine
Fatat Al Arab Agent orchestrated via LangGraph with explicit routing nodes. Autonomously routes queries, invokes CRAG to grade relevance, self-corrects via Self-RAG when faithfulness drops, maintains conversational context across bilingual queries.
Query → HyDE → Retrieve → CRAG grade → Self-RAG eval → Synthesize → self-correct → Cite
03
Concept 3
Fine-Tuning — Qalam + Kraken v5
Qalam (SwinV2+RoBERTa, WER 0.80%) and Kraken v5 segmentation fine-tuned on 20 gold-standard HITL pages. TOC Anchor Alignment creates ~300+ synthetic training pairs. LoRA adapter refresh triggered every 50 corrections.
20 HITL pages → ~300 anchor pairs → Qalam LoRA fine-tune → Kraken BLLA retrain
04
Concept 4
Evaluation — CRAG + Self-RAG
CRAG grades each retrieved document's relevance (0–1). Self-RAG evaluates faithfulness via reflection tokens: ISREL · ISSUP · ISUSE. Anchor CER verification: <10% → AUTO-ACCEPT, 10–25% → Jury, ≥25% → HITL.
CRAG: relevance ∈ [0,1] Self-RAG: ISREL · ISSUP · ISUSE Anchor CER: HIGH / MEDIUM / LOW
05
Concept 5
Governance — Zero-Hallucination
Mandatory inline citations on every result: poet name, volume, page, verse coords, image crop link. LLM architecturally constrained to only synthesize from retrieved verified chunks. Target: Hallucination Rate <2%, Citation Precision >95%.
∀ result: poet|vol|page|bbox|img LLM ⊆ retrieved context only Target: HallucinationRate < 2%
06
Concept 6
Tools & Memory — Self-Query + State
PostgreSQL Self-Query as a metadata pre-filter tool — translates "poems by حمود العبيد about battle" into SQL before semantic search. Conversational memory across bilingual turns. TOC Anchor Registry as long-term structured memory.
PostgreSQL: Self-Query pre-filter Qdrant: semantic working memory TOC Registry: structured long-term LangGraph: conversation state
